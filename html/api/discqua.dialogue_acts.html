discqua.dialogue_acts

discqua.dialogue_acts(message_list, speakers_list, msgsid_list, disc_id, conver_topic, openAIKEY, model_type='openai', model_path='', gpu=False, ctx=1, device='auto')

Annotates the utterances in a discussion using speech act labels based on the frameworks proposed by Fournier-Tombs and MacKenzie (2021) and Zhang, Culbertson and Paritosh (2017). :type message_list: list[str] :param message_list: The list of utterances in the discussion. :type message_list: list[str] :type speakers_list: list[str] :param speakers_list: The corresponding list of speakers for each utterance. :type speakers_list: list[str] :type msgsid_list: list[str] :param msgsid_list: List of messages ids corresponding to each utterance. :type msgsid_list: list[str] :type disc_id: str :param disc_id: Unique identifier for the discussion. :type disc_id: str :type conver_topic: str :param conver_topic: The topic of conversation. :type conver_topic: str :type openAIKEY: str :param openAIKEY: OpenAI API key, required if using OpenAI-based models. :type openAIKEY: str :type model_type: str :param model_type: Language model type to use, either “openai” or “transformers”. Defaults to “openai”. :type model_type: str :type model_path: str :param model_path: Path to the model, used only for model_type “transformers”. Defaults to “”. :type model_path: str :type gpu: bool :param gpu: A boolean flag; if True, utilizes GPU (when available); otherwise defaults to CPU. Defaults to False. :type gpu: bool :type ctx: int :param ctx: Number of previous utterances to include as context for each input. Defaults to 1. :type ctx: int :type device: str :param device: The device to load the model on. If None, the device will be inferred. Defaults to auto. :type device: str

Returns:

A dictionary mapping discussion IDs to lists of per-utterance dialogue act feature dictionaries.

Each entry is keyed by message ID key and contains extracted features.

Return type:

dict
