discqua.turnTaking.balanced_participation.compute_balance(contributions)
discqua.turnTaking.balanced_participation.participation(message_list, speakers_list, msgsid_list, disc_id, discussion_level)

Computes participation balance metrics by analyzing the number of messages and total words contributed by each speaker. These metrics are used to calculate entropy-based indicators of participation equality. :type message_list: list[str] :param message_list: The list of utterances in the discussion. :type message_list: list[str] :type speakers_list: list[str] :param speakers_list: The corresponding list of speakers for each utterance. :type speakers_list: list[str] :type msgsid_list: list[str] :param msgsid_list: List of messages ids corresponding to each utterance. :type msgsid_list: list[str] :type disc_id: str :param disc_id: Unique identifier for the discussion. :type disc_id: str :type discussion_level: bool :param discussion_level: A boolean flag; if True, the annotations are applied at the discussion level; otherwise at the utterance level. :type discussion_level: bool

Returns:

A dictionary containing entropy values for each discussion or each turn:

  • ’entropy_number_of_messages’: Entropy based on speaker message counts.

  • ’entropy_number_of_words’: Entropy based on total word counts per speaker.

Return type:

dict
