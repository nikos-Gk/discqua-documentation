discqua.collaboration

discqua.collaboration(message_list, speakers_list, msgsid_list, disc_id, discussion_level)

Annotates a discussion with conversational markers indicative of collaboration, such as expressions of confidence, uncertainty, pronoun usage, and idea adoption, based on Niculae and Danescu-Niculescu-Mizil (2016). :type message_list: list[str] :param message_list: The list of utterances in the discussion. :type message_list: list[str] :type speakers_list: list[str] :param speakers_list: The corresponding list of speakers for each utterance. :type speakers_list: list[str] :type msgsid_list: list[str] :param msgsid_list: List of messages ids corresponding to each utterance. :type msgsid_list: list[str] :type disc_id: str :param disc_id: Unique identifier for the discussion. :type disc_id: str :type discussion_level: bool :param discussion_level: A boolean flag; if True, annotation at the discussion level; otherwise at the utterance level. :type discussion_level: bool

Returns:

A list containing one dictionary per discussion. Each dictionary maps a discussion ID to its corresponding set of collaboration feature scores (aggregated if discussion-level, otherwise per-utterance).

Return type:

list[dict[str, dict[str, float]]]
